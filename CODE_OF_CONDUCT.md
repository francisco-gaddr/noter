# Code of Conduct

## Vår standard

Vi vill att Noter ska vara ett tryggt och professionellt open source-projekt. Alla deltagare förväntas:

- visa respekt och saklighet
- ge konstruktiv feedback
- fokusera på problem, reproduktion och lösningar
- respektera säkerhets- och sekretessgränser

## Oacceptabelt beteende

- trakasserier, hot eller personangrepp
- diskriminerande eller nedvärderande språk
- medveten publicering av privata uppgifter, secrets eller exploaterbara säkerhetsdetaljer
- spam, sabotage eller störande beteende i issues, PR:er eller diskussioner

## Moderering

Projektmaintainers får ta bort innehåll eller begränsa deltagande vid beteende som bryter mot denna policy.

## Rapportering

- Rapportera beteendeproblem till repoägaren eller maintainer via privat kontaktväg
- För säkerhetsproblem gäller [SECURITY.md](SECURITY.md)
